# 触手大战 · Tentacle Wars（网页复刻版）

原版《Tentacle Wars》（Gamezhero / FDG Entertainment，2010，Flash）的浏览器复刻。
纯前端，零依赖，零外部资源——直接用浏览器打开 `index.html` 就能玩。

```
virus-wars/
├─ index.html        界面外壳
├─ css/style.css
└─ js/
   ├─ core.js        常量、细胞、触手的模拟规则
   ├─ levels.js      23 关战役数据 + 随机对战地图生成
   ├─ ai.js          敌方菌群的行为
   ├─ render.js      Canvas 绘制
   ├─ game.js        主循环、输入、胜负判定
   ├─ audio.js       WebAudio 合成音效
   └─ main.js        菜单、存档、关卡流程
```

## 操作

| 动作 | 鼠标 | 触屏 |
| --- | --- | --- |
| 伸出触手 | 从自己的细胞拖到目标细胞（或先点自己再点目标） | 同左 |
| 剪断触手 | 点一下自己的触手 | 点一下 |
| 批量剪断 | 在空白处按住划过若干条触手 | 划一刀 |
| 暂停 / 重开 | `Esc` / `R` | 左上、右上按钮 |

## 复刻的原版规则

- 所有细胞**每 2 秒恢复 1 点能量**（`REGEN = 0.5/s`）；灰色中立细胞**不恢复**。
- 能量达到 **15 / 40 / 80 / 120 / 160** 进化一级，跌破 **5 / 30 / 60 / 100 / 140** 退化（迟滞）。
- 进化**不加快回能**，只提升**触手输送力**，并解锁可同时伸出的触手数：**1 → 2（40）→ 3（120）**。
- 触手**每一节 = 1 点能量**，由本体在生长时逐节支付；本体没能量时触手停止生长。
- 接通后持续输送：对友方 **+1**、对敌方/中立 **−1**；敌方能量归零即被同化，**重置为 10 点**，原主人从该细胞伸出的触手全部断裂。
- **剪断已接通的触手 → 触手上剩余的节数一次性注入对面**（原版的「注射」战术，可用于秒杀）；剪断尚未接通的触手则把能量退回本体。
- 通关条件：敌方细胞全部消失（教学关需占满全图）；绿色细胞全部失守则失败。

数值参考了原版社区整理的机制说明（进化门槛、每 2 秒 +1、触手上限 1~3、剪断注射），
输送速率与触手生长速度按网页版手感做了微调。

## 内容

- **战役**：23 关，逐步引入赤菌 / 蓝菌 / 紫菌 / 橙菌。紫菌最狡猾，会主动补防并使用注射战术。
- **随机对战**：可选 1~4 个敌人、三种地图规模、四档难度。
- 进度、星级、最佳用时存在 `localStorage`。

## 开发

无构建步骤。本地起个静态服务器即可：

```sh
npx http-server virus-wars -p 8080
```
