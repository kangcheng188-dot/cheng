# 超级鸡马 · 主机架（同人复刻）

《超级鸡马》（Ultimate Chicken Horse）的网页同人复刻，只做了一张地图：**主机架（Mainframe）**。
手机和电脑浏览器都能玩，支持 1–2 名本地玩家 + 1–3 个电脑对手。

- 打开 `index.html` 即可游玩（建议用任意静态服务器，例如 `npx http-server .`，这样电脑对手会在后台线程计算，更流畅）。
- 单文件版：`python3 tools/build_single.py 超级鸡马.html` 生成一个可直接双击打开、可发到手机上的 HTML。

## 玩法

每回合：**派对盒**挑道具 → 同时**放置**（搭桥或下陷阱）→ 一起**奔跑**到右边的红旗 → **计分**。

主机架的机关：坑上方两块电路板。你跑过的格子会亮起你的颜色，**下一回合变成实体方块**，再下一回合被新路径替换；炸弹炸不掉。

计分（先到 5 分获胜）：终点 1，首位 0.2，独行 0.6，陷阱每次 0.2，金币 0.2，逆袭 0.6；所有人都到 =“太简单了”，没人到 =“没有赢家”，都不计分。

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 移动 | ←→ / A D | 左半屏拖动（推到底自动冲刺） |
| 跳（按久跳高） | 空格 / ↑ / W | 右下“跳” |
| 冲刺 | Shift | “冲” |
| 放置阶段 | 方向键或鼠标移动，R/右键/滚轮旋转，空格/左键放下 | 任意处拖动移动，“旋转”“放置”按钮 |
| 其他 | Esc 暂停，F 快进，M 静音 | 右上暂停、快进 |

也支持手柄（A 跳/确认，X 冲刺，B/LB/RB 旋转，Start 暂停）。

## 代码结构

| 文件 | 内容 |
|---|---|
| `js/level.js` | 主机架地图数据（机柜、CPU 平台、两块电路板） |
| `js/physics.js` | 确定性 60Hz 角色物理（游戏与电脑共用） |
| `js/world.js` | 地形 + 道具 + 电路实体格 → 碰撞 / 陷阱 |
| `js/items.js` | 17 种道具定义、旋转、派对盒抽取 |
| `js/ai.js` | 基于真实物理的加权 A* 规划、选道具、放道具 |
| `js/ai_worker.js` `js/aipool.js` | 后台线程池 |
| `js/game.js` | 回合流程与计分 |
| `js/render.js` `js/art_*.js` `js/fx.js` | 程序化绘制的美术与特效 |
| `js/ui.js` `js/main.js` | 画布界面、触屏控制、菜单与主循环 |
| `js/audio.js` | WebAudio 合成的音效与电子乐 |
| `docs/PROMPT.md` | 制作提示词的迭代记录（v1 → v4） |

非官方同人作品，与 Clever Endeavour Games 无关；所有美术与音乐均为程序生成的原创内容。
