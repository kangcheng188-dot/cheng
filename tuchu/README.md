# 《突出重围》— 网页复刻版

复刻《和平精英 · 绿洲启元》里的创意玩法 **《突出重围》**：被仿生人军团合围的特种兵，
在不断收缩的封锁线里打完 15 关波次，最后冲向撤离点登机突围。

**在线地址**：仓库开启 GitHub Pages 后访问 `/tuchu/`
**技术**：纯前端（HTML + CSS + ES Module + three.js），无构建步骤、无后端、**离线可运行**
（three.js 已随仓库本地化，音效全部由 WebAudio 实时合成，没有任何外部资源请求）。

---

## 关于还原依据（如实说明）

《突出重围》是绿洲启元 UGC 平台上的玩法，官方没有公开完整的数值文档。
可核实的公开信息只有攻略视频与短视频标题里的这些描述：

* 属于绿洲启元创意玩法，PvE 生存突围，敌人是**仿生人**
* **波次递进**，出现过"15 关""首次通关"的说法
* 有**多张地图**（废土基地 / 丧尸营地），并迭代到 **3.0** 版本
* 武器可**进化升级**；出现过 电击步枪 / 战术弩 / M24 / M134 / 火箭筒 / 霰弹枪
* 道具有 **加速药剂 / 冰冻手雷 / 燃烧瓶 / 榴弹**
* 通关可获得**称号**；战术围绕 选点防守 / 跑路 / 苟分

本作按上述骨架 1:1 搭建，**未公开的部分**（逐关刷怪表、具体伤害数值、掉落概率）
按《和平精英》本体的真实枪械数据与手游 HUD 规范补全，
目标是"玩法结构一致、看起来打起来就是和平精英"。完整设计规格见 [`SPEC.md`](SPEC.md)。

## 玩法

```
备战期 30s（搜物资）
  → 第 1~14 关波次，每关之间 20 秒补给期（刷空投）
  → 第 5 / 10 关精英波，第 15 关首领「仿生领主·泰坦」（三阶段）
  → 突围阶段：撤离点开启 → 跑过去坚守 40 秒 → 直升机撤离
  → 结算：击杀 / 伤害 / 命中率 / 存活 / 评分 → 称号
```

* **封锁线**：红色能量护栏把战场围住，第 7、13 关各收缩一次（82m → 68m → 54m），
  脱离作战区域会持续掉血；打完首领后封锁线被击穿，撤离通道打开。
* **倒地机制**：血量归零先倒地爬行、只能用手枪，10 秒内用急救包/医疗箱自救；
  「重整旗鼓」次数用尽即失败（普通 3 次 / 困难 2 次 / 地狱 1 次）。
* **武器进化**：每把枪独立充能，白 → 绿 → 蓝 → 紫 → 金，
  满级解锁特化（步枪贯穿 / 霰弹火焰弹 / 狙击爆炸弹头 / 冲锋吸血 / 机枪免弹药 /
  弩 5 穿 / 电击连锁翻倍 / RPG 爆炸范围翻倍）。
* **10 种仿生人**：仿生兵、突击兵、爆破自爆、侦察无人机、重装（正面护盾）、
  狙击手（红色激光）、纵火、电击（致盲）、精英督军、BOSS 泰坦。
* **14 把枪**：P92 / S686 / S12K / UMP45 / M416 / AKM / M24 / AWM / M249 /
  M134 / 战术弩 / 电击步枪 / RPG-7 / 平底锅。
* **道具**：绷带、急救包、医疗箱、能量饮料、加速药剂、破片手雷、燃烧瓶、
  冰冻手雷、烟雾弹、二/三级头盔与防弹衣、弹药箱、空投。

## 操作

| 动作 | 键鼠 | 触屏 |
|---|---|---|
| 移动 / 疾跑 | WASD / Shift | 左摇杆（推满即疾跑） |
| 视角 | 鼠标（点击画面锁定指针） | 右半屏拖动 |
| 开火 / 开镜 | 左键 / 右键 | 开火键（左右各一） / 开镜键 |
| 换弹 · 跳 · 蹲 · 趴 | R · 空格 · C · Z | 对应按键 |
| 切枪 | 1 / 2 / 3、滚轮 | 点武器槽 |
| 投掷 / 切换投掷物 | G / B | 手雷键 / 切换键 |
| 拾取 | F | 拾取键 |
| 药品 | 4 ~ 8 | 左侧药品竖排 |
| 暂停 | Esc | 左上暂停键 |

> 站在沙袋、矮墙前会自动翻越；靠近哨塔阶梯可以爬上去架点。

## 性能

* 粒子、曳光、伤害飘字全部对象池化，HUD 的 DOM 引用全部缓存并做脏检查，
  每帧只写变化的部分。
* 暂停菜单里可切「流畅 / 均衡 / 高清」，分别调整渲染分辨率与阴影。
* 移动端 HUD 会按屏幕高度整体等比缩放（`--hs`），矮屏不会挤成一团。
