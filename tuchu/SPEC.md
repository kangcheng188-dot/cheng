## 1. 总体形态

- **视角**：第三人称越肩视角（TPS，和平精英默认），开镜切换为准心收拢的瞄准视角。
- **平台**：纯前端，单页，无构建步骤，可直接 GitHub Pages 托管；three.js 本地化（离线可跑）。
- **画面**：低多边形废土基地，黄昏沙尘天光，体积雾，动态阴影。
- **语言**：全中文 UI，字体与配色对齐和平精英（军绿/沙色底 + 橙黄高亮 + 红色警告）。
- **适配**：桌面键鼠 + 移动端触屏双摇杆，横屏优先，安全区适配。

## 2. 玩法流程（必须完全一致的骨架）

```
开始界面（玩法介绍 + 难度选择 + 地图选择）
   ↓
空投落地 → 拾取初始物资（30 秒备战期）
   ↓
第 1 关 ─ 第 14 关：波次围攻（仿生人从四面包围圈内推进）
   每关之间 20 秒【补给期】：空投箱刷新 / 回血 / 换枪
   第 5、10 关为【精英波】，第 15 关为【首领波】
   ↓
第 15 关：首领「仿生领主·泰坦」
   ↓
【突围阶段】撤离点在地图边缘开启 → 跑到撤离点 → 坚守 40 秒 → 直升机撤离
   ↓
结算：击杀 / 伤害 / 命中率 / 存活时长 / 评分 → 称号
```

### 2.1 硬性规则
- **包围圈**：一圈红色能量护栏（"封锁线"）把玩家困在基地内，随关卡推进逐渐**收缩**，
  逼迫玩家向中心决战（对应"重围"）。碰到封锁线持续掉血。
- **无限复活关闭**：本模式为单命 + 3 次「重整旗鼓」自复活（倒地读秒 10 秒可被治疗/自救）。
- **倒地机制**：血量归零先进入**倒地**（爬行、只能用手枪），10 秒内使用急救包自救成功则重新站起，
  否则淘汰。共 3 次机会。
- **胜负**：坚守到撤离直升机 = 通关；机会耗尽 = 失败（显示"突围失败"）。

### 3.1 BOSS 三阶段
1. **阶段一（100%~66%）**：机炮扫射 + 召唤仿生兵。
2. **阶段二（66%~33%）**：装甲展开，弱点核心暴露（爆头点 3×伤害）；释放导弹齐射。
3. **阶段三（33%~0%）**：狂暴，全场激光扫描 + 持续召唤爆破仿生人；场地边缘燃烧。

### 3.2 AI 要求
- 从**包围圈四周**的刷新门（8 个方位）生成，向玩家推进（"重围"感）。
- 简单避障 + 分离力（不叠在一起）；有视线检测，被掩体挡住会绕行。
- 受击有硬直、击退、血条飘字；爆头 2 倍伤害且有特殊音效与"爆头"提示。

### 4.2 武器进化（原版关键词"武器进化"）
- 每把枪独立的**进化槽**，用该枪击杀充能。
- 5 个等级：`白 → 绿 → 蓝 → 紫 → 金`，需 8 / 20 / 40 / 70 次击杀。
- 每级：伤害 +12%、弹匣 +20%、后坐 −10%、换弹 −8%。
- 满级（金）解锁**特化效果**：步枪→穿透 2 人；霰弹→火焰弹；狙击→爆炸弹头；
  冲锋→吸血 8%；机枪→不消耗弹药 3 秒；特殊武器→范围加倍。
- HUD 上枪名边框随品质变色，满级有金色流光。

### 4.3 枪械手感
- 后坐力：垂直上跳 + 随机水平散布，连发递增，松开后 0.3s 回正。
- 弹道：可见曳光弹（每 3 发一根），命中有火花/血雾。
- 换弹动画 + 换弹进度条；空仓自动提示"按 R 换弹"。
- 开镜：FOV 从 75 → 40（狙击 → 25），准心收拢，灵敏度降低，屏幕轻微暗角。
- 命中反馈：准心变红 + 命中十字（hitmarker）+ 伤害飘字（爆头为橙色加粗）。

## 6. HUD（必须逐项对齐和平精英）

```
┌────────────────────────────────────────────────────────────┐
│ [队伍头像/血条]   [ 罗盘刻度条 N 30 60 E … ]   [方形小地图] │
│                                                 [存活/击杀] │
│                                                 [击杀播报]  │
│                                                             │
│                          ✛ 准心                              │
│                      (受击方向红色扇形)                       │
│ [药品竖排]                                                   │
│                                                  [开镜][蹲] │
│  ◎ 左摇杆        [═════ 血条 + 能量条 ═════]      [趴][跳]  │
│                  [武器槽1][武器槽2][手雷]         ◉ 开火键   │
└────────────────────────────────────────────────────────────┘
```

必备元素清单：
1. **罗盘刻度条**（顶部居中）：`北/东/南/西` + 数字刻度，随视角滚动。
2. **方形小地图**（右上）：地形轮廓、玩家箭头、敌人红点、空投图标、撤离点图标、封锁线圆环。
3. **存活人数 / 击杀数**（小地图下方）：`剩余敌人 xx` `击杀 xx`。
4. **击杀播报**（右上滚动）：`你 使用 M416 淘汰了 仿生突击兵`，带武器图标。
5. **分段血条**（底部居中）：绿色，受伤变黄→红；上方叠加**黄色能量条**。
6. **护甲/头盔图标**（血条左侧）：显示等级与耐久。
7. **武器槽卡片**（底部右）：枪名、品质边框、`当前弹药/备弹`、进化槽小条。
8. **左虚拟摇杆**（底部左，移动端）：跟随触点，带方向环。
9. **右侧按钮组**：开火（大圆）、开镜、蹲、趴、跳、换弹、手雷、拾取、加速药剂。
10. **药品竖排**（左中）：绷带/急救包/医疗箱/能量饮料，带数量角标。
11. **受击方向指示**：屏幕中心外的红色扇形，指向伤害来源。
12. **准心**：四段式动态准心，移动/射击时扩散。
13. **关卡横幅**：每关开始时中央大字 `第 X 关 · 名称`，带扫描线动效。
14. **补给期倒计时**：顶部中央 `补给期 00:20`。
15. **BOSS 血条**：顶部横条 + 阶段分段。
16. **封锁线警告**：进入封锁线时全屏红色脉冲 + `警告：脱离作战区域`。
17. **低血量**：屏幕四周红色血迹渐显 + 心跳音。
18. **结算面板**：击杀/伤害/命中率/存活/评分/称号，和平精英式深色卡片。

### 自检中发现并修复的问题

1. **`data.js` / `audio.js` 尾部混入了一行 `</content>`** → 模块整体加载失败（`Unexpected token '<'`）。已清理。
2. **场景过暗**，人物与掩体全成剪影 → 提高环境光/半球光、增加反向补光、提高曝光、整体提亮材质配色。
3. **手雷落地后仍高速滑行**，落点漂到目标外十几米 → 加落地摩擦与撞墙反弹。
4. **RPG 火箭与相机平行发射**，近距离必偏 → 改为从枪口指向准心命中点（弹道收敛）。
5. **移动端摇杆/按键完全不显示** → `input.touch` 在 `initInput` 内才赋值，却在之前就用它判断了 `desktop` 类；改为提前探测 + 首次 touch 兜底。
6. **矮屏 HUD 元素过大**互相重叠 → HUD 整体等比缩放 + 触屏专用布局。
7. **敌人被沙袋等低掩体卡住走不到玩家**，波次可能永远打不完 → 加"翻越低掩体"（玩家同样可翻）、扇形上下文转向、卡死脱困、以及"长时间无进展就以增援形式重投到玩家附近"的兜底。
8. **哨塔立柱把敌人夹住** → 立柱改为纯装饰（不参与碰撞）。
9. **封锁线顶部有一条横贯天空的亮线** → 纹理 `wrapT` 从 Repeat 改 ClampToEdge（透明顶边与不透明底边环绕插值所致）。
10. **`state==='wave'` 而关卡号越界时崩溃** → 加边界保护。
