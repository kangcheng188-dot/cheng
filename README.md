# 绝命毒师宇宙 · 人物关系图谱

《绝命毒师》（Breaking Bad）与《风骚律师》（Better Call Saul）的交互式人物关系网络、事件时间线与人物档案库。

单文件网页，无任何外部依赖 —— 直接用浏览器打开 `index.html` 即可。

## 内容

| | |
|---|---|
| 人物 | 62 位，按 9 个阵营归档 |
| 关系 | 166 条，分 7 种类型（血缘 / 伴侣 / 搭档 / 雇佣 / 师徒 / 敌对 / 致其死亡） |
| 事件 | 59 个关键事件，其中 27 个重大转折，跨 1980s – 2010 |

## 三个视图

**关系网络** — Canvas 力导向图谱。每个人物是一块带元素符号与档案编号的方块（取自剧名 Br / Ba 的周期表母题），颜色代表阵营。

- 点击方块打开卷宗；关联人物高亮，其余淡出
- 悬停查看简介；拖动方块可固定位置；滚轮 / 双指缩放，拖拽平移
- 双击聚焦到某个人物
- 侧栏可按剧集、阵营、关系类型筛选，并在「力导向」与「阵营分组」两种布局间切换
- 关系标签沿连线放射排布，带自动避让，不会互相压字

**事件时间线** — 按 7 个纪元排列的完整时序，从 1989 年泳池边的马克斯之死，到 2010 年探监室里的那支烟。每个事件标注剧集、集数与卷入其中的人物，点击人物直接跳到关系网中的对应位置。

**人物档案** — 按阵营归档的卡片墙，含身份、档案、代表台词与结局。

## 其他

- 深色（沙漠夜）/ 浅色（漂白卷宗）双主题，跟随系统并可手动切换
- 响应式：桌面三栏、平板抽屉式卷宗、手机折叠侧栏
- 支持 `prefers-reduced-motion`，键盘 `/` 聚焦搜索、`Esc` 取消选中

## 结构

`index.html` 一个文件，分三层：

- **数据层** — `FACTIONS` / `RELTYPES` / `CHARS` / `LINKS` / `ERAS` / `EVENTS`，改这里就能增删人物与事件
- **应用层** — 力学模拟、Canvas 渲染、筛选与视图切换
- **样式层** — CSS 自定义属性定义的双主题 token，Canvas 绘制时从中读取颜色，主题切换自动生效

> 剧透警告：包含两部剧全部结局。
