# cheng

## 毒师宇宙人格元素表

`index.html` —— 一个单文件网页，分析《绝命毒师》与《风骚律师》共 55 个角色的 MBTI 类型，
并把每一个判断的推断过程写出来。

- **§01 元素表**：55 个角色按四个气质族（NT / NF / SJ / SP）排布成元素表，可按剧集、族群、关键词筛选。
- **§02 读法**：四步推断流程（先定主导功能 → 再看劣势功能 → 只采信有代价的行为 → 不用道德排序），
  以及关于 MBTI 效力的说明。
- **§03 核心档案**：20 个主要角色的完整档案，含认知功能栈、论点、3–5 条带剧集出处的场景证据、反方读法。
- **§04 配角档案**：35 个配角的简要推断。
- **§05 同型不同人**：六组对照（三个 INTJ、三个 ISTJ、两个 ENTP……），说明类型决定了什么、没决定什么。
- **§06 类型分布**：55 人的类型分布表。
- **§07 争议清单**：长期存在两种读法的角色，逐条列出分歧点落在哪个具体问题上。

共 117 条场景证据，每条标注剧集与集名。

### 技术说明

单个自包含 HTML 文件，无外部依赖：IBM Plex Mono 已子集化后以 data URI 内嵌，
中日韩文字走系统字体栈。同时适配浅色与深色主题；四个气质族的配色经过色盲可辨性校验。

直接用浏览器打开 `index.html` 即可。
